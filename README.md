## ⚙️ Compilation

Most C exercises can be compiled using:

```bash
cc -Wall -Wextra -Werror file.c
```

Then executed with:

```bash
./a.out
```

For projects containing a `Makefile`:

```bash
make
```

Clean object files:

```bash
make clean
```

Clean everything:

```bash
make fclean
```

Recompile the project:

```bash
make re
```
